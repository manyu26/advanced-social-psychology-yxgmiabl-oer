## Chapter summary

The self is both the subject and object of reflection. Its representations vary in accessibility, social level, and temporal orientation. Such variation can coexist with enduring patterns, while felt clarity and continuity remain distinct from accuracy.

Self-judgment depends on the information people encounter, select, interpret, and retain. Its validity requires a defensible criterion and separately defined accuracy measures. Self-esteem and self-evaluative motives then explain why favorable feedback, confirming feedback, and useful feedback may prompt different choices. The final section tests those distinctions through a feedback-use design.

## Core dependency chain

- Specify the represented self-aspect.
  - This enables a prediction about context and accessibility.
- Identify information and processing.
  - This enables a process explanation rather than a label for the outcome.
- Define the accuracy criterion and measure.
  - This enables separate tests of calibration and association.
- Specify evaluation and motive.
  - This enables competing predictions about feedback selection and use.
- Measure subsequent action.
  - This enables a distinction between subjective relief and demonstrable improvement.

## Section-level concept map and objectives

### 4.1 Representation

**Learning objectives:**

- **4.1a:** Explain how self-representation can be context-sensitive and stable.

**Concept flow:** Self as agent and object → identities → accessible self-knowledge → stable conditional patterns → clarity and continuity.

### 4.2 Social foundations

**Learning objectives:**

- **4.2a:** Distinguish personal, relational, and collective self-representations without reducing culture to national categories.

**Concept flow:** Personal qualities → close relationships → memberships → cultural dimensions → authenticity and environmental fit.

### 4.3 Processing

**Learning objectives:**

- **4.3a:** Trace how information selection, interpretation, and memory influence self-judgment.

**Concept flow:** Situation choice → feedback elicitation → attention → interpretation → recall → weighting.

### 4.4 Accuracy

**Learning objectives:**

- **4.4a:** Distinguish rank-order accuracy from mean-level bias and evaluate self–other knowledge differences.

**Concept flow:** Construct → criterion → association and signed error → self–other access → metaperceptions.

### 4.5 Self-esteem

**Learning objectives:**

- **4.5a:** Separate self-esteem level, scope, timescale, stability, and contingency when evaluating evidence.

**Concept flow:** Worth evaluation → scope and timescale → level and variability → contingencies → measurement and temporal inference.

### 4.6 Functions

**Learning objectives:**

- **4.6a:** Compare proposed functions of self-esteem and distinguish narcissism from self-compassion.

**Concept flow:** Inclusion and status signals → competing functional accounts → self-esteem versus narcissism → self-compassion.

### 4.7 Motives

**Learning objectives:**

- **4.7a:** Differentiate self-enhancement, self-verification, and self-improvement using competing predictions.

**Concept flow:** Desired favorability → consistency with existing beliefs → actual change → feedback selection → later use.

### 4.8 Integration

**Learning objectives:**

- **4.8a:** Evaluate self-judgment biases and design a test of feedback use that separates feelings from change.

**Concept flow:** Comparative judgment → evidence standard → cognitive and motivational explanations → intervention → separate affect and performance outcomes.

## Common student bottlenecks

| Bottleneck | Conceptual repair |
|---|---|
| Assuming that contextual variation proves insincerity | Separate stored self-knowledge, momentary accessibility, and repeatable person–situation patterns. |
| Using nationality as an individual psychological diagnosis | Measure the specific self-construal dimension and examine within-group variation. |
| Explaining every positive self-view with the same motive | Identify the stage at which evidence changes and specify an alternative mechanism. |
| Treating a high correlation as proof of calibration | Require both an association statistic and signed errors on comparable scales. |
| Equating state with domain-specific or trait with global | Cross the scope and timescale distinctions rather than merging them. |
| Reducing narcissism to extreme confidence | Separate worth, superiority, entitlement, and responses to setbacks; do not diagnose from vignettes. |
| Assuming a request for criticism uniquely proves an improvement motive | Separate valence, consistency, usefulness, and credibility of feedback. |
| Treating feeling better as proof of improved skill | Measure mood, engagement, calibration, and blinded performance separately. |
